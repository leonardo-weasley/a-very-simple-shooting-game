# 火线对决 · LAN 对战版

基于 Three.js 的 3D 网页 FPS，支持局域网联机对战。

## 运行方法

### 启动服务器（房主）
​```bash
node server.js
​```

### 局域网联机
1. 房主运行 `node server.js`，记下控制台显示的地址（如 http://192.168.1.10:8080）
2. 局域网内其他设备浏览器打开该地址
3. 输入代号 → 点「加入对战」

### 单人练习
直接点「离线练枪」，无需服务器。

## 操作
| 按键 | 功能 |
|---|---|
| WASD | 移动 |
| 鼠标左键 | 开火 |
| 右键 | 瞄准（AWM） |
| R | 换弹 |
| 1-5 | 切枪 |
| Tab | 战绩板 |
| Enter | 聊天 |

## 环境要求
- Node.js 14+（零依赖，无需 npm install）
- Chrome / Edge 浏览器
